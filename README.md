# Real-Time AI Voice Clone & Audio Deepfake Detection System

A production-ready, modular FastAPI backend for detecting voice clones and deepfake audio streams in real-time. Built with PyTorch, Hugging Face Transformers (`mo-thecreator/Deepfake-audio-detection`), Librosa, WebSockets, and Supabase.

---

## 🌟 Key Features

- **Real-Time Streaming**: High-throughput WebSocket endpoint (`/ws/detect`) for streaming 2-second audio chunks with minimal latency.
- **HTTP Fallback**: Multipart/form-data upload endpoint (`POST /analyze-chunk`) for standard file analysis.
- **Audio Preprocessing**: Standardizes incoming audio to 16kHz mono PCM, decodes Base64 payloads, and pads short signals (<0.5s) to guarantee model stability.
- **AI Classification**: Leverages pretrained Hugging Face Transformer audio classification models with automated GPU (CUDA) acceleration and softmax risk confidence scoring.
- **Call Session Summary**: Aggregates risk metrics across call chunks (`GET /call-summary/{call_id}`) and evaluates automated final verdicts (`REAL`, `SUSPICIOUS`, `FAKE`).
- **Database Integration**: Async logging into Supabase database tables (`call_logs` & `call_sessions`).

## 🛠️ Installation & Setup

### 1. Prerequisites
- Python 3.10 or higher
- Optional: NVIDIA GPU with CUDA drivers installed for GPU acceleration

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure Environment

Copy `.env.example` to `.env` and configure your credentials:

```bash
cp .env.example .env
```

`.env` contents:
```env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key-here
MODEL_ID=mo-thecreator/Deepfake-audio-detection
HOST=0.0.0.0
PORT=8000
DEBUG=False
```

## 🗄️ Supabase Database Schema

Run the following SQL in your Supabase SQL Editor to create the required tables:

```sql
-- Table: call_logs
CREATE TABLE IF NOT EXISTS call_logs (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    call_id TEXT NOT NULL,
    chunk_id TEXT NOT NULL,
    phone_number TEXT NOT NULL,
    risk_score INT NOT NULL,
    risk_level TEXT NOT NULL,
    color TEXT NOT NULL,
    is_fake BOOLEAN NOT NULL,
    aasist_score FLOAT,
    reason TEXT,
    model_used TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Table: call_sessions
CREATE TABLE IF NOT EXISTS call_sessions (
    call_id TEXT PRIMARY KEY,
    phone_number TEXT NOT NULL,
    total_chunks INT NOT NULL,
    avg_risk_score INT NOT NULL,
    max_risk_score INT NOT NULL,
    final_verdict TEXT NOT NULL,
    start_time TIMESTAMPTZ,
    end_time TIMESTAMPTZ,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Indices for performance optimization
CREATE INDEX IF NOT EXISTS idx_call_logs_call_id ON call_logs(call_id);
```

## 📡 API Endpoints Summary

### 1. Health Check
`GET /health`
- **Response**:
```json
{
  "status": "healthy",
  "cuda_available": true
}
```

### 2. Real-Time WebSocket Streaming
`WS /ws/detect`
- **Request Payload (JSON)**:
```json
{
  "call_id": "call_12345",
  "chunk_id": "chunk_001",
  "phone_number": "+1234567890",
  "audio_data": "<base64_encoded_audio_string>"
}
```
- **Response Payload (JSON)**:
```json
{
  "chunk_id": "chunk_001",
  "call_id": "call_12345",
  "risk_score": 88,
  "risk_level": "HIGH",
  "color": "RED",
  "is_fake": true,
  "reason": "Spectral anomalies and unnatural acoustic patterns detected.",
  "confidence": 0.8842,
  "timestamp": "2026-09-01T16:15:00.000Z"
}
```

### 3. HTTP Chunk Upload Fallback
`POST /analyze-chunk`
- **Form Data**:
  - `call_id`: `call_12345`
  - `chunk_id`: `chunk_001`
  - `phone_number`: `+1234567890`
  - `file`: `<audio_file_binary>`

### 4. Call Session Aggregated Summary
`GET /call-summary/{call_id}`
- **Response**:
```json
{
  "call_id": "call_12345",
  "phone_number": "+1234567890",
  "total_chunks": 12,
  "avg_risk_score": 82,
  "max_risk_score": 95,
  "final_verdict": "FAKE",
  "start_time": "2026-09-01T16:10:00.000Z",
  "end_time": "2026-09-01T16:10:24.000Z"
}
```
